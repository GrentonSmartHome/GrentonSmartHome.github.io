What's New

5.15.29 (build 2641A)

20 October 2026

  • Analog In/Out DIN v2.0.1:
    • Added new ONE_WIRE_HUB object for 1-Wire sensor diagnostics and sensor re-discovery without restarting the module:
      • ConfiguredSensors - number of the hub's 1-Wire sensors in the project,
      • ActiveSensors - number of project sensors detected during the last search,
      • InactiveSensors - number of project sensors not detected during the last search,
      • ReportedSensors - number of all detected sensors, including those not in the project,
      • RefreshSensors method - searches for 1-Wire sensors again without blocking the TFBus,
      • OnRefreshCompleted event - triggered when the sensor search is finished.
  • Added automatic 1-Wire sensor re-discovery after a module restart when some project sensors were not detected.
  • Improved device communication on the TF-Bus (issue with the module disappearing).
  • DALI Controller v4.0.5:
    • Fixed reading of ballast group membership when ballast addresses are not consecutive.
    • Fixed group colour temperature range in the SetGroupColourTemperature method of the DALI_MASTER object - the range is now determined from all ballasts in the group that support colour temperature, not only the first one.
  • Extended the list of supported FAKRO Z-Wave devices with new ARZ actuator variants:
    • ZWAVE_FAKRO_ARZ_ZWRC_V1, ZWAVE_FAKRO_ARZ_ZWRC_V2 - supported in the same way as ZWAVE_FAKRO_ARZ_ZWR,
    • ZWAVE_FAKRO_ARZ_ZWRCS_V1, ZWAVE_FAKRO_ARZ_ZWRCS_V2 - supported in the same way as ZWAVE_FAKRO_ARZ_ZWR.
  • Fixed Multisensor methods:
    • EraseFlash in the IR_CONTROLLER object - erasing stored IR codes from the device,
    • Recalibration in the AIR_CO2_SENSOR object - forcing CO2 sensor calibration.
  • Added a retry mechanism for NTP time synchronisation - the time is updated even when the router needs more time to establish a connection after start-up.
  • Fixed display of high 1-Wire sensor serial numbers in the SensorSerialNumber feature (shown with a minus sign). The feature now returns the full 48-bit sensor ROM number, which also changes the value for some sensors that were previously displayed correctly.
  • Added logging of the cloud login process.
